# スターターキット：AIと一緒にアプリを育てる

AGY（AIエージェント）と一緒に、アプリを計画して、作って、理解しながら育てていくためのひな形です。
ゲームでも、ツールでも、記録アプリでも、作りたいものは何でも大丈夫です。

## 使い方

**ゼロから作るとき**
1. このフォルダをまるごとコピーして、アプリの名前を付ける（例：`book-memo`）
2. `docs/plan.md` の「1. ひとことで言うと」と「2. できること」を書く（ぼんやりでOK）
3. そのフォルダでAGYを起動して、`docs/prompts.md` の「A」を渡す

**すでにコードがあるアプリに使うとき**
1. このフォルダの中の `.agents` と `docs` を、アプリのフォルダにコピーする
2. アプリのフォルダでAGYを起動して、`docs/prompts.md` の「A'」を渡す

## 入っているもの

| ファイル | 中身 |
|---|---|
| `docs/plan.md` | 計画シート。何を作るか、何ができたか、次に何を作るか |
| `docs/prompts.md` | AGYへの頼み方（プロンプト集）。どの場面でどれを使うかの表が先頭にあります |
| `docs/explain/progress.md` | どこまで理解できたかの記録。全体の何割を理解したかがわかります |
| `docs/explain/questions.md` | わからないことリスト |
| `.agents/rules/plan-rules.md` | AGYへの決まり。AGYが自動で読み込みます（隠しフォルダなので見えないことがあります） |

## 流れ

```
A 計画を練る → B 小さな機能に分ける → C 最初の版を作る
      ↓
E 機能を追加する ⇄ D1 読む → D2 深掘りする（何回でも）→ D3 確かめる
```

作ることと理解することは、好きな順番で進めて大丈夫です。理解が途中でも、機能はいつでも追加できます。

> `docs/` の中の図（Mermaid）は、GitHub やエディタのプレビュー表示で図として見られます。
