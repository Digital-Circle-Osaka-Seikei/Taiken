## 2. 決まったこと【本人】

- 友人が暇そうにしているときに、スマホやPCでさっと見せて、ひっぱって飛ばすだけで遊んでもらえるようにする
- 1台で、1人で操作して遊ぶ
- 味方のボールも自分で動かす
- ボールをひっぱって離すと飛んでいき、壁で跳ね返りながら敵にぶつかってダメージを与えるゲーム
- 操作するボールは完全に止まったら別のボールに移り、ずっと順番に回る
- 敵は止まっている。敵は5体。味方は3個
- 全ての敵を倒したら勝ち。負けはない。飛ばせる回数に上限はない
- 1ターン＝ボールを1回ひっぱって飛ばすこと
- 指もマウスも使えるようにしたい
- スタート画面と、倒したときの画面が欲しい。何ターンで倒せたかを画面に出す（保存は不要）
- 「2. できること」の次にやりたいこと（上から順に作る）
  1. ボールをひっぱって飛ばせるようにする
  2. 敵に当たったらHPを削る（HP0で敵が倒れる）
  3. 友情コンボ（飛んでいるボールが味方のボールに触れると、味方が追加の攻撃をする）

## 3. 解釈・仮決め

### 【AGY解釈】（本人が「それで合っている」と答えたもの）
- 「味方」と「味方のボール」は同じもの（味方3個はボール）
- 「ボールが止まった」は完全に止まったとき
- 「5回当たれば倒せるくらい」は、1回当たるとHPが1減る（HP5）
- 「ボールの数」は、操作する1個と味方3個で合計4個
- 「ダメージ」は、HPを減らすことと同じもの

### 【AGY仮決め】（数や見た目など、あとで変えてよいもの）
- 壁：画面の四辺（段階2で確認する）
- 友情コンボの味方の攻撃：敵のHPを1減らす
- 敵5体の並べ方：画面の上の方に横一列
- 見た目・色・大きさ・光り方：段階3以降でまとめて仮に決めて示す
