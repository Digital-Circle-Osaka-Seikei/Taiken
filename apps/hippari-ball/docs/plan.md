# 計画シート：ひっぱりボール

<!--
使い方
- 自分で書くのは「1」と「2」だけで大丈夫です。残りはAGYと相談しながら埋めます
- 「2」はぼんやりした大きなやりたいことだけでもOKです
- AGYへの頼み方は docs/prompts.md を見てください（最初はプロンプトA）
-->

## 1. ひとことで言うと

自分が、友人が暇そうにしているときに、スマホやPCでさっと見せて「ひっぱって飛ばすだけ」で遊んでもらえるようになるもの
（ボールを指やマウスでひっぱって離すと飛んでいき、壁で跳ね返りながら敵にぶつかってダメージを与える、ひっぱりアクションのゲーム）

## 2. できること

<!--
「大きなやりたいこと」はぼんやりで大丈夫です（例：ゲームを遊べるようにしたい）。
その下に、1回で作れる「小さな機能」を並べます。
小さな機能の目安は「作ったあと、動いたかどうかを目で確かめられる」大きさです。
分解はAGYと一緒にやります（docs/prompts.md の B）。
-->

- **今できていること**（新しく作るときは「まだなし」で大丈夫です）
  - まだなし
- **次にやりたいこと**（上から順に作ります）
  - [ ] ボールをひっぱって飛ばせるようにしたい（ひっぱった向きと反対に飛び、壁で跳ね返る）
  - [ ] 敵に当たったら、ちゃんとHPを削ってほしい（HPが0になったら敵が倒れる）
  - [ ] 友情コンボがほしい（飛んでいるボールが味方のボールに触れると、味方が追加の攻撃をしてくれる）

## 3. 仕組みの見立て

<!--
「2. できること」の機能ごとに、どういう仕組みで動きそうかを書きます。
コードを自分で書けるかどうかではなく、ロジックを日本語で説明できるかが基準です。
- ロジックが説明できれば、動く部品がわからなくても「イメージできること」に入れてOKです
- 動く部品は、作ったあとにAGYに教えてもらって書き足せば大丈夫です
- ロジック自体が思いつかないものだけ「まだイメージできないこと」に入れます
-->

- **仕組みがイメージできること**
  - ［ 「2」の機能 ］
    - ロジック：［ どんな順番・条件で動くか（日本語で） ］
    - 動く部品：［ わかればファイルや関数の名前。わからなければ空欄 ］
- **まだ仕組みがイメージできないこと**：［ 「2」の機能 ］
- **本格的にするのに必要なもの**：［　　］

## 4. アプリの地図（AGYが書く）

<!--
最初は空欄で大丈夫です。画面のイメージだけ、わかる範囲で書いておきましょう。
覚えておくものやファイル構成は、作りながらAGYが書き足していきます。
自分は、書かれた内容を読んで「そういう地図になっているのか」を確かめます。
いらない項目は「なし」になります。
-->

- **画面**
  <!--
  画面ごとに「何をすると → どの画面へ行くか」を並べます。
  ボタンが複数あるときや、条件によって行き先が変わるときは、1行ずつ分けて書きます。
  書き方の例：
    - タイトル画面
      - 「スタート」を押す → ゲーム画面
      - 「遊び方」を押す → 遊び方画面
    - 遊び方画面
      - 「戻る」を押す → タイトル画面
    - ゲーム画面
      - 玉に当たる → ゲームオーバー画面
    - ゲームオーバー画面
      - ハイスコアを更新したとき → 名前入力画面
      - 更新しなかったとき → 「もう一度」でゲーム画面、「タイトルへ」でタイトル画面
  -->
  - ［ 画面の名前 ］
    - ［ 何をすると ］ → ［ どの画面へ ］
- **覚えておくもの（データ）**：［ 何を、どこに保存するか ］
- **ファイル構成**：［ どのファイルが何の役割か ］
