## 1. ひとことで言うと

自分が、友人が暇そうにしているときに、スマホやPCでさっと見せて「ひっぱって飛ばすだけ」で遊んでもらえるようになるもの
（ボールを指やマウスでひっぱって離すと飛んでいき、壁で跳ね返りながら敵にぶつかってダメージを与える、ひっぱりアクションのゲーム）

## 2. できること

<!--
「大きなやりたいこと」はぼんやりで大丈夫です（例：ゲームを遊べるようにしたい）。
その下に、1回で作れる「小さな機能」を並べます。
小さな機能の目安は「作ったあと、動いたかどうかを目で確かめられる」大きさです。
分解はAGYと一緒にやります（docs/prompts.md の B）。
-->

- **今できていること**（新しく作るときは「まだなし」で大丈夫です）
  - まだなし
- **次にやりたいこと**（上から順に作ります）
  - [ ] ボールをひっぱって飛ばせるようにしたい（ひっぱった向きと反対に飛び、壁で跳ね返る）
  - [ ] 敵に当たったら、ちゃんとHPを削ってほしい（HPが0になったら敵が倒れる）
  - [ ] 友情コンボがほしい（飛んでいるボールが味方のボールに触れると、味方が追加の攻撃をしてくれる）
  - 小さな機能（作る順。【本人】＝本人が書いた、【AGY】＝AGYが足した。確かめ方つき）
    1. [x] 画面の土台：ブラウザでページを開くと、ゲームの場所が表示される【AGY】
       - 確かめ方：ブラウザでページを開き、ゲームの場所が見える
    2. [x] マウスでひっぱって離すと、反対向きに同じ速さで飛ぶ（速さは長さに関係なく同じ）【本人】
       - 確かめ方：マウスで引っ張って離すと、反対向きに同じ速さで飛ぶ
    3. [x] 壁に当たると跳ね返る（入射角＝反射角、回数上限なし、少しずつ減速）【本人・AGY仮決め】
       - 確かめ方：壁で角度どおりに跳ね返り、だんだん遅くなる
    4. [ ] 指（スマホ）でも同じように飛ばせる【本人・AGY】
       - 確かめ方：スマホで指で引っ張って離すと同じように飛ぶ
    5. [ ] ボールを4個置き、止まったら順番の次のボールに移る【本人・AGY】
       - 確かめ方：止まったボールが残り、次のボールが操作できる
    6. [ ] 敵5体を置き、当たるとHPが減る（5回で倒れる量）【本人】
       - 確かめ方：敵に5回当てるとHPが0になる
    7. [ ] HPが0になったら敵が倒れて消える【本人】
       - 確かめ方：HPを0にすると敵が消える
    8. [ ] 敵を全部倒したら勝ち画面を出し、ターン数を表示する【本人・AGY】
       - 確かめ方：全部倒すと勝ち画面が出て、回数が表示される
    9. [ ] スタート画面を作り、「スタート」でゲーム画面へ【本人・AGY】
       - 確かめ方：スタートを押すとゲーム画面に切り替わる
    10. [ ] 操作中のボールが味方に当たると、コンボが発動する【本人】
       - 確かめ方：当てたとき、コンボの表示などで発動がわかる
    11. [ ] コンボで、当たった味方から真上にビームを出し、真上の敵にダメージ【本人・AGY仮決め】
       - 確かめ方：真上にいる敵のHPが減る
    - 作る順番の理由：6と7の後に8、6・7・10の後に11が作れるように並べた

## 3. 仕組みの見立て

<!--
「2. できること」の機能ごとに、どういう仕組みで動きそうかを書きます。
コードを自分で書けるかどうかではなく、ロジックを日本語で説明できるかが基準です。
- ロジックが説明できれば、動く部品がわからなくても「イメージできること」に入れてOKです
- 動く部品は、作ったあとにAGYに教えてもらって書き足せば大丈夫です
- ロジック自体が思いつかないものだけ「まだイメージできないこと」に入れます
-->

- **仕組みがイメージできること**
  - 機能2：マウスでひっぱって飛ばす
    - ロジック：ボールを押して離す。押した位置と離した位置の向きを見る（長さは見ない）。反対向きに、長さに関係なく同じ速さで飛ぶ【本人】
    - 動く部品：game.js の ball（位置と速さ）、drag（ひっぱり中か）、toCanvasPos()（マウス・指の位置の直し）、pointerdown / pointermove / pointerup（ひっぱりの開始・線・飛ばす。マウスも指も同じ）、update()（1コマずつ進める）、draw()（描く）、loop()（くり返す）
  - 機能3：壁で跳ね返る
    - ロジック：壁に当たったら、ぶつかる角度を見る。入射角と同じ角度で跳ね返る。回数上限なし。跳ね返るたびに多少減速する【本人】
    - 動く部品：game.js の update()（左右・上下の端で向きを反対にし、跳ね返るたびに速さを減らす）、BOUNCE_SLOWDOWN（跳ね返るたびの減速の数字。0.85）、ball（速さ vx・vy）
  - 機能5：止まったら次のボールへ
    - ロジック：減速して完全に止まったら、止まった場所に残し、順番の次のボールが操作できるようになる【本人】
    - 動く部品：
  - 機能6：敵のHP
    - ロジック：ボールが敵に当たるとHPが減る。1回の減り方は強さに関係なく一定。5回で0になり、敵が倒れる【本人】
    - 動く部品：
  - 機能10・11：友情コンボ（ビーム）
    - ロジック：操作中のボールが味方に当たったら、当たった味方の真上にいる敵の全部にダメージ【本人】
    - 動く部品：
- **まだ仕組みがイメージできないこと**
  - 機能4：指（スマホ）でひっぱって飛ばす
    - ロジック：まだ本人の言葉になっていません。AGYの案（本人の言葉ではない）：指で押して離す。マウスと同じ計算で、反対向きに同じ速さで飛ぶ
    - 動く部品：game.js の pointerdown / pointermove / pointerup / pointercancel（マウスと指を同じ書き方で受け取る）、index.html の canvas の touch-action（指でページが動かないようにする）
- **本格的にするのに必要なもの**：［　　］

## 4. アプリの地図（AGYが書く）

<!--
最初は空欄で大丈夫です。画面のイメージだけ、わかる範囲で書いておきましょう。
覚えておくものやファイル構成は、作りながらAGYが書き足していきます。
自分は、書かれた内容を読んで「そういう地図になっているのか」を確かめます。
いらない項目は「なし」になります。
-->

- **画面**
  <!--
  画面ごとに「何をすると → どの画面へ行くか」を並べます。
  ボタンが複数あるときや、条件によって行き先が変わるときは、1行ずつ分けて書きます。
  書き方の例：
    - タイトル画面
      - 「スタート」を押す → ゲーム画面
      - 「遊び方」を押す → 遊び方画面
    - 遊び方画面
      - 「戻る」を押す → タイトル画面
    - ゲーム画面
      - 玉に当たる → ゲームオーバー画面
    - ゲームオーバー画面
      - ハイスコアを更新したとき → 名前入力画面
      - 更新しなかったとき → 「もう一度」でゲーム画面、「タイトルへ」でタイトル画面
  -->
  - スタート画面
    - 「スタート」を押す → ゲーム画面（【AGY仮決め】）
  - ゲーム画面
    - 敵を全部倒す → 勝ち画面
  - 勝ち画面
    - 「もう一度」を押す → ゲーム画面（【AGY仮決め】）
    - 「スタートへ」を押す → スタート画面（【AGY仮決め】）
- **覚えておくもの（データ）**：ゲーム中の数字（ボールの位置・速さ、ひっぱった回数・HP）だけ。保存はしない
- **今ある画面**：ゲームの場所だけ（機能1のページ1つ）。上の3つの画面は、この先の機能で作る予定
- **ファイル構成**
  - index.html：ページ本体。ゲームの場所（canvas）を置き、窓に全部入る大きさを決める。指で動かしたときにページがスクロールしないようにする（機能4で追加）
  - game.js：ゲームの場所に絵を描き、ボールをマウスや指でひっぱって飛ばし、壁で跳ね返すコード（ボールは1個。毎コマ描き直す）
  - 変えていないもの：README.md、docs/、.agents/
